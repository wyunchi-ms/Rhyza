# 设计原则

[文档地图](README.md) · [产品记忆与设计原则](product-memory-and-design-principles.md) · [使用指南](user-guide.md)

本页是项目级视觉与交互规则的入口。已确认的分支、引用、知识对象和预览语义以[产品记忆与设计原则](product-memory-and-design-principles.md)为准；[功能矩阵](features.md)说明当前实现程度，设计材料不代表已实现。

## 视觉语言

- 工作台优先：中性表面、可辨认的分隔、克制的青绿色强调；不要在单个页面发明新的主题系统。
- 浅色、深色、高对比度与减少动画应使用同一语义变量体系。变量在 `src/theme.css`，公共外壳在 `src/interface.css`，页面布局在 `src/pages/`。
- 图标与控件保持一致的 hover、focus-visible、disabled 状态；文字不能依赖低对比度浅灰。

## 交互边界

- 从历史回答追问、选择引用与查看知识是连续的阅读流程；不能因提交新分支而抢走当前阅读位置。
- 设置页隐藏工作区侧边栏，左侧是设置分类，右侧只显示选中的分区；窄窗口改为可横向浏览的分类栏。返回应用不改变原工作区侧边栏的开关状态。
- 工作区底部快捷入口属于工作区侧边栏，侧边栏收起时一起隐藏。
- `HashRouter` 的 hash 用于路由，设置分区不能使用会覆盖路由的裸 `#heading` 链接。

变更这些规则时，同时更新相关的 UI 测试、[使用指南](user-guide.md)和[功能状态](features.md)（若能力发生变化）。
